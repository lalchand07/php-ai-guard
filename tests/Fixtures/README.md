# Recorded sample responses

These bodies are copied from (or shaped exactly like) the examples in each
provider's official API reference, read on 2026-10-17. They let the tests run
without network access or API keys.

| File | Source |
|---|---|
| `anthropic/*.json` | https://platform.claude.com/docs/en/api/messages (Response 200 example) and https://platform.claude.com/docs/en/api/errors ("Error shapes") |
| `gemini/*.json` | https://ai.google.dev/api/generate-content (GenerateContentResponse, UsageMetadata, PromptFeedback JSON representations) |
| `openai/*.json` | https://github.com/openai/openai-openapi (chat.completion example, CompletionUsage schema) |
| `openrouter/*.json` | https://openrouter.ai/docs/api-reference/overview (ResponseUsage type) |
